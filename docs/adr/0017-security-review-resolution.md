# ADR-0017: Resolution of the security review of ADR-0013 to ADR-0016

- Status: Accepted
- Date: 2026-11-10
- Deciders: owner
- Decided by: owner-delegated (architect), review at MVP
- Spec chapters affected: 2, 3, 5, 8, 9, 10, 11, 12 and `spec/grammar/egide.ebnf`
- Raised by: security-reviewer T-1038 (reviews of PR #14 and PR #15, "BLOCKING")

## Context

The red-team review blocked the delegated decisions on four points (S1, S2, B1, B2) and listed follow-ups that must be
fixed in the spec before the named implementation tasks start. Rule applied: the most conservative, secure-by-default
option; where the reviewer offered alternatives, the rejected ones are listed below.

## Alternatives rejected

| Option | Why not |
|--------|---------|
| S1: restore the old narrow LEX-050 (no C0/C1) | Simpler, but the no-allowlist decision (ADR-0016) depends on escapes for ZWJ/ZWNJ/U+FE0F; terminal programs would lose `"\u{1B}"`. Output hygiene is needed anyway. |
| S2: forbid all `Cn` | Validity would depend on the compiler's Unicode version (reproducibility). |
| S2: enumerate more ranges | The reviewer's gap (about 3,700 unassigned DICP) shows enumeration fails; properties are stable. |
| B1: nominal wrapper `type X = new kube.Clientset` | Cleaner scope, but changes the Go type mapping (GO-030); manifest gate first, wrapper as a later ADR. |
| B1: root manifest only | PKG-031 deliberately makes breaches visible at every level; consistency wins. |
| B2: sentence only | A grammar-level guarantee is cheaper to trust than an evaluator check; both are done. |
| #15 F4 option B (`let Ok(v) = f() else Err(e):`) | New syntax; revisit if usage shows the swallow pattern. |

## Not acted on (documented residual risks, per the review)

- A literal no-break space inside a string looks like U+0020; confusable letters in string literals (Cyrillic `а`);
  no Unicode normalisation of strings. Strings are data; identifiers are ASCII (LEX-020). A TR39 mixed-script audit
  lint for strings used in comparisons is task T-1040 (low priority).
- Raw HTML in `##` doc comments is an injection vector for `egide doc`: task T-1040.
- Dependencies' `@integration` tests must not run under the root's `egide test --integration`: task T-1040.

## Consequences

- Complexity budget: three small rules (LEX-006, SYN-006, SYN-018) and eleven diagnostics; no new syntax except the
  mandatory `reason` on `@go_threadsafe` and the grammar restriction on top-level `let`.
- Security: closes the four blockers; the INT-001 data-race hole of ungated `@go_threadsafe` is closed by manifest gating.
- Implementation: T-1033 (table generator, now larger), T-1031, T-1036, T-1037, T-0005 logs updated; new T-1039 (output
  hygiene function) and T-1040 (tooling follow-ups).
- Migration: none (pre-1.0).
