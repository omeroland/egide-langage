## Goal

`main` is green again on both CI compiler jobs. Today the job `compiler (OCaml 5.3)` fails on `main` (a8ab071)
at `opam install . --deps-only --with-test --with-dev-setup` because `dune-project` pins the dev-setup dependency
`ocamlformat (= 0.26.2)`, and `ocamlformat-lib.0.26.2` requires `ocaml < 5.3`, so opam finds no solution. After this
task the pin (and `.ocamlformat`'s `version=`) is on a release installable on OCaml 5.2 and 5.3.

## Context

- Failing run: https://github.com/omeroland/egide-langage/actions/runs/36290182609 (job `compiler (OCaml 5.3)`,
  "No solution found": `ocamlformat = 0.26.2 → ocamlformat-lib = 0.26.2 → ocaml < 5.3`).
- `egide.opam` is generated from `dune-project` (`generate_opam_files true`) and is committed.
- T-0024 formats the seed and makes the format check blocking; it must use the new version, so it should depend on
  this task.
- `.github/` is protected and is not touched: the format step stays `continue-on-error` until T-0024.

## Log

- 2026-11-09 release-manager: claimed. Root cause confirmed from the job log of run 36290182609.
- 2026-11-09 release-manager: chose **0.28.1**. Evidence from `ocaml/opam-repository` (master) opam files:
  - 0.27.0: `ocamlformat-lib` has `ocaml >= 4.08` but the `ocamlformat` package has `ocaml >= 4.08 & < 5.4`, so the
    same breakage would come back as soon as CI adds OCaml 5.4. Rejected.
  - 0.28.1: `ocamlformat` and `ocamlformat-lib` both `ocaml >= 4.08`, no upper bound; supports OCaml 5.3 and 5.4
    syntax (CHANGES.md); a patch release on the 0.28 line. Dependency list identical to 0.29.0 apart from the OCaml
    lower bound.
  - 0.29.0: also no upper bound (`ocamlformat-lib` needs `ocaml >= 4.14`), but it is the newest release and carries
    extra output-changing items on top of 0.28 (odoc parser 3.0 re-indents code blocks in doc comments, which
    matters with our `parse-docstrings = true`; default `ocaml-version=5.4` makes `effect` a keyword). Its successor
    is already fixing a non-idempotency in it (unreleased section of CHANGES.md). Not needed for 5.3; can be adopted
    later in a dedicated bump + reformat task.
  - Reasoning: 0.28.1 is the most mature release that installs on 5.2 and 5.3 without a known upper bound that would
    re-break CI on 5.4, and its formatting output is the one T-0024 will freeze.
- 2026-11-09 release-manager: `.ocamlformat` `version = 0.28.1`; `egide.opam` regenerated by `dune build` (one-line

  T-1005. T-0024 now depends on T-0028; its acceptance criterion still says "ocamlformat 0.26.2" and should be read
