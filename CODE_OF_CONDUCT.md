# Code of conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; critique code and designs, not people.
- Assume good faith. Explain the *why* of a review comment and propose a fix.
- No harassment, discrimination or personal attacks, in any language.

Reports go to the project owner through GitHub (private message or the security reporting channel).
The owner decides on actions, from a warning to a permanent ban.
